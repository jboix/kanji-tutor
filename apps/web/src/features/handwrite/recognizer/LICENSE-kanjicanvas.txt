The handwriting recognizer in this folder (geometry.ts, distance.ts, stroke-map.ts, classify.ts)
is a TypeScript port of KanjiCanvas, and patterns.json is generated from its reference patterns
(docs/resources/javascript/ref-patterns.js, hand-drawn with jTegaki; the XML sources are in the
same repository) by scripts/handwrite-patterns.ts.
